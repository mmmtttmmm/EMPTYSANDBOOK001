## What is a Repository?

A **repository** (often shortened to "repo") is a storage location for your project. Think of it as:

- **A project folder** - It contains all your files and folders for a specific project
- **A time machine** - It tracks every change made to your files, so you can see what changed, when, and by whom
- **A collaboration space** - Multiple people can work on the same project without overwriting each other's work

## What's Inside a Repository?

- **Files and folders** - Your actual project content (code, documents, images, etc.)
- **History** - A complete record of all changes ever made
- **Branches** - Different versions of your project you can work on simultaneously
- **README file** - This file! It explains what the project is about

## Why Use GitHub?

GitHub hosts your repositories online, making it easy to:
- Back up your work
- Share projects with others
- Collaborate with team members
- Track issues and tasks
- Showcase your portfolio
